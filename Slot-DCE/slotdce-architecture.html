SLOTDCE DETECTOR-LITE

矿井不均匀照明修正模型

当前唯一数据流：无损降采样编码 → 自适应有序曝光 Slot → 方向受限色调渲染 → 全分辨率细节重建。训练与推理执行同一个前向过程。

1

输入与曝光分析

RGB 输入归一化至 [0,1][B,3,H,W]
→
亮度与颜色统计Y、RGB 最大/最小值、饱和度[B,1,H,W]
→
边缘感知照明半分辨率低频统计后回到 H×Willumination
→
连续软权重暗部、亮场、白光、灯芯、邻灯与光晕6 × [B,1,H,W]
2

H/4 共享特征编码

PixelUnshuffle ×4只重排像素，不丢弃空间信息；1×1 投影到 48 通道[B,48,⌈H/4⌉,⌈W/4⌉]
→
48 通道特征深度可分离残差块 → 深度卷积 + 1×1 → 残差块
→
48 → 64深度卷积负责空间混合，1×1 负责通道混合
→
多尺度上下文三个深度可分离残差块，d=1/2/3features [B,64,H4,W4]

所有可学习 3×3 空间卷积都在 H/4 网格执行；原图分辨率只保留亮度分析、显式渲染和 Retinex 细节运算。

3

自适应先验与有序 Slot 路由

图像曝光描述16-bin 软直方图 + 亮度均值 + 标准差18-D
→
轻量 MLP预测五个正区间宽度；累计边界产生严格有序中心与 σ18 → 16 → 5
→
内容 + 曝光先验content logits 与高斯曝光 logits 相加后 softmaxattention [B,5,H4,W4]
→
Slot 聚合与强度注意力加权特征、使用率和中心共同预测每个 Slot 强度slots [B,5,64]
S1深暗区 · 只能提亮
S2暗区 · 只能提亮
S3中性 · 增益固定为 0
S4较亮区 · 只能压暗
S5最亮/白光 · 只能压暗
4

共享预测头与四类控制量

局部强度头

对暗部、亮场、白光 Slot 强度做有界空间调制。

光晕头

结合小/大邻域光幕增量，预测相对压暗与光幕移除。

细节头

预测细/中/粗三尺度对数反射率增益及可靠度。

饱和恢复头

PixelUnshuffle ×4 后预测 RGB 残差与恢复置信度。

5

方向受限渲染与 RGB 输出

低频色调修正暗部增加正 ΔY；亮场、白光、灯芯和光晕增加负 ΔY
→
防黑环补偿用邻域亮度下限限制光晕移除，避免边缘形成黑圈
→
Retinex 细节重建只增强输入中仍可靠存在的多尺度结构
→
恢复与色域约束融合可信饱和恢复，保持 RGB 比例和输出范围enhanced [B,3,H,W]
6

无配对训练与四项损失

Ltone

暗部提亮、亮场/白光/灯芯压暗与光晕目标。

Ltexture

可靠区域对数亮度梯度保持。

Lrecovery

同一无配对输入合成过曝后的 RGB 恢复。

Lsmooth

不跨真实边缘的色调场与光晕场平滑。

L = L_tone + 0.25 L_texture + 0.50 L_recovery + 0.05 L_smooth
当前实现：68,819 个可学习参数；仅支持 slotdce_v9_8_detector_lite；无旧版本分支、checkpoint 迁移或推理后处理。
