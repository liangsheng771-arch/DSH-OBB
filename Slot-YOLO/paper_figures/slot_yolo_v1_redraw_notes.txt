连接关系：
1. RGB image -> YOLOv8s backbone (Raw branch)
2. RGB image -> SlotDCE -> YOLOv8s backbone (Enhanced branch)
3. Raw P3 + Enhanced P3 + scale-aligned Slot guidance -> ISAF -> fused P3
4. Raw P4 + Enhanced P4 + scale-aligned Slot guidance -> ISAF -> fused P4
5. Raw P5 + Enhanced P5 -> P5ResidualFusion -> fused P5
6. fused P5 + scale-aligned raw Slot guidance -> IG-LSF-AIFI -> A5
7. fused P3 + fused P4 + A5 -> Geometry CCFF v1 -> output P3/P4/P5
8. output P3/P4/P5 -> YOLOv8s OBB head -> oriented detections

重绘要点：
- 骨干两路独立传播，共享非 BN 的可学习参数，BN 参数和统计量独立；融合结果不送回下一骨干阶段。
- P3/P4 融合是 ISAF；P5 融合是 P5ResidualFusion，不能把 P5 标成 ISAF。
- IG-LSF-AIFI 只作用于 P5。
- ISAF 实际使用 guidance adapter 生成的 16 通道引导；IG-LSF-AIFI 使用对应尺度的原始 10 通道 SlotDCE 引导。整体图用同一虚线引导表示，各自适配操作省略。
- Geometry CCFF v1 包括原生 CCFF 和仅作用于 P3 的 GeometryGuidedP3Fusion。P4/P5 不接收几何修正后的 P3 反馈。
- v1 的几何模块以原生 P3 和 top-down P4 lateral 特征为输入；整体黑盒图将这些过程封装在 Geometry CCFF v1 中。
- P3/P4/P5 的 stride 为 8/16/32，通道数为 128/256/512。
- OBB 标签在训练中监督几何场，推理不需要标签。本整体图省略训练专用损失和监督箭头。
- 这是结构与版式参考，不包含模型性能结果或真实检测示例。
